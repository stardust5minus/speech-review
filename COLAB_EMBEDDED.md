# Speech Review: embedded Colab interface

Upload `SpeechReview_Colab.ipynb` to Colab and run the cells in order. This version uses Colab's notebook iframe proxy rather than a public tunnel. Use the tabs inside the embedded interface; separate browser windows may not share the same proxy storage.

Optionally enable Drive persistence before importing recordings. Otherwise, download saved results before the runtime ends. Save transcript edits before MFA alignment and save reviewed boundaries before exporting human TextGrids.

Choose English or 中文 in the interface header. Transcripts and filenames retain their original content. For a full interface in a separate browser tab, including iPad access, use `SpeechReview_Colab_Public.ipynb` and follow [the public URL instructions](COLAB.md).
